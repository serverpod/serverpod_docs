# scloud app

The `scloud app` commands publish your Flutter app to TestFlight and Google Play. They set the app up, check it, publish it, and follow, cancel, or download its builds.

See [App publishing](/cloud/concepts/app-publishing) for the full workflow, including connecting the stores in the console. The `project.app` settings in [scloud.yaml](/cloud/reference/scloud-yaml-schema#app) set the defaults for `scloud app setup`, `scloud app doctor`, and `scloud app publish`.
