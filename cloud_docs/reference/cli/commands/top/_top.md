# scloud top

The `scloud top` command shows a live overview of your project in the terminal. It covers the last hour of podlets, traffic, and the database, plus the latest deployments and logs, and keeps updating until you quit.

The overview needs an interactive terminal. In CI or a script, use [`scloud status live`](/cloud/reference/cli/commands/status) and [`scloud log`](/cloud/reference/cli/commands/log) instead.

For CPU, memory, traffic, and database charts over longer time ranges, open [Metrics](/cloud/concepts/metrics) in the console.
